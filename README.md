# Flashcard Generator

Tool sederhana untuk membuat dan menyimpan flashcard belajar dalam format JSON.

## Cara Pakai
1. Jalankan flashcard_generator.py
2. Masukkan pertanyaan dan jawaban
3. Flashcard tersimpan otomatis di flashcards.json

## Teknologi
- Python
- JSON

## Limitasi
- Input manual, belum otomatis dari teks
- Belum ada UI

## Next Improvement
